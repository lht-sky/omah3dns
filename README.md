# omah3dns

Website portofolio omah3dns, rumah karya Lukman. Tayang di **https://lht-sky.github.io/omah3dns/**.

| Folder | Isi |
|---|---|
| `index.html` | Halaman utama portofolio |
| `assets/` | Logo omah3dns dan favicon |
| `museum-audio/` | Simulasi 3D audio interaktif museum |
| `trommel-miniature/` | Model 3D dan video uji trommel miniatur |
| `mini-conveyor-cv350/` | Model 3D mini belt conveyor CV350 |

Untuk menambah proyek baru: unggah folder baru berisi `index.html`, lalu di `index.html` utama salin satu blok `<article class="sheet">` di bagian Karya dan ganti isi serta tautannya ke folder baru.
