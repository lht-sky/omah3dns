Saya merancang mesin, lalu mengajarkannya.

- 🧩 **Cetak 3D & spare part**: part pengganti, jig, bracket, prototipe
- ⚙️ **Desain mesin & CAD**: dari ide klien ke konsep 3D, lalu gambar kerja, STEP, dan STL
- 🔌 **Elektronik & otomasi**: panel kontrol, ladder logic, perangkat berbasis Arduino
- 📚 **Kelas & materi vokasi**: materi ajar dari kelas saya
